Start the server from the repository root with cIQenv/bin/python -m uvicorn --app-dir server app:app --port 8000. Your DeepSeek key and cloud credentials stay on that server.

Find contradictions in your documents

Add documents, and corpusIQ compares every sentence with its closest matches. A fine-tuned DeBERTa filter (v4) picks the pairs worth checking, and two LLM judges decide which ones conflict.

    Public links or pre-signed links (S3, Google Cloud Storage, Azure SAS, Dropbox, OneDrive direct links).

    Leave the keys empty to use the server's AWS credentials (environment, ~/.aws, or an instance role).

    Leave both empty to use AZURE_STORAGE_CONNECTION_STRING on the server.

    Otherwise the server uses its Google application-default credentials (gcloud auth application-default login).

    Settings

    The 0.003 cutoff kept all 16 confirmed contradictions in the WikiContradiction test set while sending 28% of candidate pairs to the judges. With two judges each pair costs two LLM calls.
